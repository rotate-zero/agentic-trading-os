# Diagrams

Currently empty. The pipeline and architecture diagrams that exist today are inline ASCII in `../architecture/system-design.md` and `../architecture/trading-intelligence-architecture.md` — they're the source of truth and stay there so they don't drift from the text describing them.

This folder is for standalone rendered diagrams (Mermaid `.mmd`/`.md`, or exported `.svg`) once a diagram is complex enough that ASCII stops being the clearer format — e.g. the full pipeline sequence diagram, or an entity-relationship diagram for the database schema in `../architecture/system-design.md` §4.13. Add one file per diagram, and link to it from the architecture doc section it illustrates rather than duplicating the explanation here.
